# 植物图标

- 来源：`素材库\植物`（纪元1800 植物园素材）
- 共 59 张 PNG：`plant_001.png ... plant_059.png`，由 `tools/import_assets.py` 复制并生成 `src/04c-plants.js` 图鉴数据（含中文名、英文名、花园套装、大洲、稀有度）。
- 图鉴数据含中文名、英文名、花园套装、大洲、展示稀有度（蓝/紫/金）与原始稀有度（普通/罕见/稀有/史诗/传说）。
- 展示稀有度按大洲配额：**每个大洲 1 金 + 3 紫**，其余蓝色（合计 6 金 / 18 紫 / 35 蓝）。
  - 金色：亚洲·孟加拉榕、非洲·宝石塔、北美洲·“佩里巨型阳光”莲花、南美洲·巴西坚果树、欧洲·神圣莫利草、大洋洲·巨星珊瑚。
  - 花园套装仅保留在数据中，界面不再显示套装行。
- 素材库里不少 `.png` 实际是 WebP，导入脚本会统一解码并保存为真正的 PNG。
- 图片仅用于本项目的帝国宝藏（植物园）功能；版权/使用范围请遵循素材原出处。
